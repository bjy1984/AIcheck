# 审查输出与判定

输出面向监检人员，使用中文。审查由当前 AI 平台执行，结果写入当前会话或用户指定的本地目录。先给出用户标识的工程名称（如有）、节点、资料清单和内容哈希、规则来源／版本、调用的辅助服务及覆盖情况，再列问题。工程名称是报告标签，不是后台工程 ID。系统不保存工程文件或本次报告；服务执行失败不作为业务结论。

## 每条核查记录

| 字段 | 内容 |
| --- | --- |
| 节点与方法 | R24 / 方法 3 等，引用实际 v3 章节，不能发明规则编号 |
| 核查对象 | 文件、管线、焊工、焊口、炉批或计算书的实际标识 |
| 执行状态 | 未执行、执行中、已完成、执行失败、待补充资料 |
| 结果 | 符合、不符合、预警、证据不足、需人工核查、不适用；未完成时可为空 |
| 实际值 | 原文取值及单位；缺失则写“未提供／不可读”，不推测 |
| 要求值／依据 | 已核实的标准号、版本、条款、适用条件；未核实要明确写出 |
| 证据 | 用户提供的文件名称、内容 SHA-256、实际页码／定位、简短摘录；无法计算哈希时如实注明 |
| 问题与下一步 | 缺什么、差在哪、应补什么、关联哪个节点复核 |

“符合”需要适用要求清楚、完整证据和明确比较；缺页、缺参数、无法核实标准、仅目录／封面不能据此判符合。“不符合”需要适用的明确要求和违反它的证据。资料找不到不等同于证明业务事实不存在；证书平台查无结果不等于伪证。预警适用于存在风险或边界待确认；不适用需有范围证据或监检人员确认，不能用文件匹配数量判断。

v3 的 R07 等包含“已批准／未批准／链不闭环”专用结果时保留其业务原意，同时说明证据与复核状态，不强制压成肯定／否定二选一。

## 覆盖与汇总

按每个节点全部方法列覆盖情况：已核查、缺资料、缺能力／依据、已确认不适用。先展示不符合、预警、证据不足等问题，再列通过项。若只查了 R24 身份一致性，证书有效期、施焊日期、项目范围仍未核查，应写“部分核查完成，待补资料”，而不是“R24 符合”。

宿主平台完成 OCR 只是完成了输入预处理；标准查询和证件核验也是辅助能力，均不证明已穷尽 v3。报告须保留未覆盖项目；不能把 OCR 完成或证件接口可用等同于节点符合。没有执行的远程核验应写明“未核验”，不能以本地字段比对代替官方核验记录。

资料内容变化后重新计算哈希；旧结果仍引用旧内容。标记“采用资料已更新，旧结论待复查”，经用户确认使用新内容重新审查，不把旧证据引用自动替换到新文件。同名文件也必须以内容区分。

## OCR 与字段整理约定

宿主 AI 平台负责读取用户提供的资料并完成必要的 OCR，整理结果仅保存在当前会话或本地。每条提取记录至少保留：

| 内容 | 要求 |
| --- | --- |
| 原文件名 | 使用用户提供文件的实际名称，区分同名文件 |
| 内容标识 | 可获取时计算 SHA-256；无法获取时注明原因，不生成假哈希 |
| 原始页码 | 指向原件；另附页面印刷页码或表格行号有助于定位时一并记录 |
| 原文／定位 | 保留可核对的原文片段或明确的区域、表格、对象定位，不将摘要冒充原文 |
| 结构化字段 | 字段名称、原文取值、规范化值（如有）和单位；每个值都有对应证据 |
| 不确定标记 | 明确缺失、模糊、冲突、推断及需回看原图的内容；不得凭空补填 |

日期、证件号、标准号、焊工编号、炉批号、数值及单位是易误识别字段，核验前回看原件。格式规范化须保留原值；无法确认的字符不作为确定性核验输入。平台没有 OCR 能力或内容识别不足时，请用户提供可检索 PDF、文本，或先完成平台识别；标记受影响核查项为缺证据，继续其余可执行项目。AIcheck MCP 不接收原文件、页面图像或整份 OCR 正文。

## 服务证据与文件定位

- 文件证据引用本地原件；PDF 的物理页序号与页面印刷页码有差异时同时注明，OCR 分片或截图需保留它与原文件页码的对应关系。提取子集后不得把子集第 1 页误写成原件第 1 页。
- 标准证据记录标准号、版本、条款、文本来源和查询时间。系统“已收录”只说明有资料，不等于官方“现行有效”；有效性未知时明确注明。
- 证件核验记录所用来源、查询时间、身份匹配结果、有效区间及施工基准日期。报告中不必要的身份证号、账号和凭据应省略或脱敏。证件到期日计算、字段一致性、官方真实性、作业范围覆盖分别陈述。
- MCP 只发送标准查询条件或最少的证件核验字段；原文件、OCR 正文、证据索引和本次报告保留在当前会话或本地。报告记录实际调用的服务与能力限制，不嵌入服务令牌，也不宣称宿主平台或官方核验平台零留存。

## 例：R24 缺施焊日期

已有证书显示有效期至 2027-03-31，但未提供施焊记录或焊口台账日期。结果为“证据不足”，实际值分别记录证书到期日与施焊日期缺失；建议补充施焊记录及焊工—焊口对应关系。不能因为证书今天未到期就断言覆盖了实际施工。示例日期只用于解释，不作为用户工程事实。

所有输出为辅助意见，由监检人员确认后形成正式结论；本 skill 不执行签字、盖章、正式验收或批量改变工程节点状态。
