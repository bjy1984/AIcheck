# 離線證據回歸

此處只測本地工具與人工編寫的案例，沒有模型審計、改進者或服務器連線。候選 B 不在測試流程中，現行 skill 不因這些測試而被替換。

`fixtures/evidence-boundaries.json` 有 11 組合成場景，每組提供事實前提、預期結論、關鍵事實和錯誤報告變體。工程標識、主體、要求均為虛構；不是任何真實工程的標準答案。測試以真實 `check_report` 和 `score` 執行，案例期間禁止 socket 連線與子程序。

| 類別 | 正反例及驗收 |
|---|---|
| 讀圖 | 「復印無效」不能推出「復印件」；讀不清不能判違反；明確是復印件且缺規定印章則不能一概改為待人工。另以無文字層合成頁測裁切、放大、紅色像素保留及完整頁不被覆寫。 |
| 主體關聯 | 圖簽與工程標識不一致需要關聯證據；客戶、製造與施工是不同角色。缺交易鏈與有完整交易鏈分開測，錯引無關文件只能得到部分事實分。 |
| 結論分類 | 缺規則或必要事實為證據不足；事實齊全但需現場判斷為人工確認；已證實違反、不適用及技術上未執行各有反例。追溯項不能在前項缺證或有衝突時通過。 |
| 主條款 | `test_score.py` 檢查父條款與子項的同頁正文、直接複合條號、完整引用；錯標準、錯頁、錯父項、相鄰子項、跨存檔拼接、目錄、空正文、查詢失敗、未引用均不能充當完整取證。 |

案例中的預期報告是手工寫的，測試通過只表示評估器能分辨這些受控輸入。它沒有讓模型讀圖或自行發現主體；也沒有將自然語言理由變成可靠的自動裁決器。關鍵事實仍採關鍵詞及引用核對，不理解否定、語義或完整交易鏈；85% 的總分也不保證每個事實滿分。案例回歸需逐項檢查，不可只看總分或 `all_pass`。

圖像測試只驗證 helper 提供的圖像未丟失，不驗證字讀對了。條款檢查限於可辨識的行首條號與同頁層級；頁首頁尾、跨頁條款、非數字子項等未知版式須覆核。它只證明取得帶標號的文字，不能證明文字涵蓋完整要求或理解正確。

從倉庫根目錄執行（`TMPDIR` 應指向倉庫外已存在的臨時目錄）：

```bash
NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost \
PYTHONDONTWRITEBYTECODE=1 backend/.venv/bin/python -m unittest discover \
  -s skills/aicheck-node-audit-dev/tests -p test_evidence_regressions.py -v

NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost \
PYTHONDONTWRITEBYTECODE=1 backend/.venv/bin/python -m unittest discover \
  -s skills/aicheck-node-audit-dev/tests -p test_score.py -v
```

完整測試另需 `HARNESS2_SRC` 指向本地 harness2；適配器測試用假 Codex 執行檔，不呼叫模型。既有測試中的節點編號只用於合成資料，不會執行真實工程審計。

重播真實歷史報告時，只讀既有產物，另存結果並記錄評估器版本及輸入雜湊，不覆寫歷史結果。不能把重新評估工具的結果當成模型表現改善。若將來另獲模型測試授權，應保留未提供給審計者的預期答案，先凍結案例與判準再運行；不得把本目錄折進運行時 skill。
