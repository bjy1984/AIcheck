# 常用标准条文页码

页码是仓库 `rules/standards/` 原件的 PDF 物理页（从 1 起），已对着原件核过。先在这里找页，再用 `$PY $S ocr --bundle $B --files standard:rules/standards/<文件名>.pdf` 取逐页 OCR、`$PY $S text --file rules/standards/<文件名>.pdf --bundle $B --pages <物理页>` 只转那几页（不自己看图；表格数值、符号矩阵 OCR 拿不准的，靠这些数值的结论交人工确认），引用时写 `standard:rules/standards/<文件名>.pdf` 加物理页。有的原件是扫描件、没有文字层（下面注明）；有文字层的可以 `$PY $S text --file <原件> --bundle $B` 转出后检索，`--- 第 N 页 ---` 就是物理页。表格页的文字层常错位或乱码，数值以服务器 OCR（表格按格展开）为准，仍拿不准就交人工确认：跑过 `ocr --files` 后，`text` 对乱码页、扫描件自带识别文字的页、拆成一格一行的表格页只给 OCR 文字；没跑时 `text` 的 `layerWarnings` 列出这些页。

服务器 `standard-content --section` 常定位不到附录条款，返回 `ok` 但条款为空时也一样，直接用这里的页码。

## 仓库里没有的标准

下面这些评测里碰到过、仓库 `rules/standards/` 没有原文，服务器标准库也不能当原文用。资料按它们评定、验收的（如 PQR 按 NB/T 47014-2011 评定、管件按 GB/T 12459-2017 制造），涉及版本差异的项判证据不足或需人工确认，`limitations` 写明缺哪份原文：GB/T 12459-2017、GB/T 13401-2017、GB/T 14976-2012、GB/T 2102、NB/T 47008-2017、NB/T 47014-2011、TSG Z6002-2026。
