# AIcheck 数据服务 · 用户发布版 1.1.1

提供 MinerU OCR、标准全文与状态、证件登记与有效期计算；支持 AI 根据证据开展人员—材料—工艺匹配。无需下载项目后端或 MinerU 模型。需要 Python 3.10+ 和管理员提供的可访问后台。

## 1. 准备

向管理员获取 **HTTPS 服务地址和自己的访问令牌**。令牌过期后需重新登录获取。不要使用其他人的令牌或 MinerU 供应商密钥。

将 ZIP 解压到固定文件夹，例如 `C:\AIcheck\aicheck-data-services` 或 `~/AIcheck/aicheck-data-services`。之后移动文件夹需要重新生成配置。服务地址不要填写他人电脑的 `127.0.0.1`。

在 WorkBuddy 的技能导入入口导入本目录 Skill；如果入口接受 ZIP，可导入原始发布包。MCP 脚本仍需保留在本机固定目录。安装 Skill 与启用 MCP 是两个步骤。

## 2. 生成配置

打开终端，使用实际解压路径运行：

macOS / Linux：

```sh
python3 "$HOME/AIcheck/aicheck-data-services/scripts/setup_workbuddy.py"
```

Windows PowerShell（已安装 Python 启动器时）：

```powershell
py -3 "C:\AIcheck\aicheck-data-services\scripts\setup_workbuddy.py"
```

依次输入服务地址、允许上传的资料文件夹路径、个人访问令牌。路径输入不需加引号。令牌输入隐藏，单独写入个人目录，不会出现在配置 JSON 中。

默认生成 `~/.aicheck/workbuddy/mcp.json` 和个人令牌文件。Unix 新建文件权限为 0600；Windows 请使用本人用户目录，勿放到共享目录。向导拒绝覆盖已有文件，更新时可用 `--output` 指定新文件名；若复用已有令牌文件，使用 `--token-file`。

支持多个资料目录，示例：

```sh
python3 scripts/setup_workbuddy.py --base-url https://YOUR-SERVICE-HOST --allow-root "/path/to/documents" --allow-root "/path/to/another-folder" --token-file "/private/path/token.txt" --output "/private/path/mcp-new.json"
```

示例域名和路径必须替换；发布包不内置公共服务器地址或共享令牌。

## 3. 在 WorkBuddy 启用 MCP

打开生成的 `mcp.json`，将 `mcpServers` 内的 `aicheck-data-services` 条目合并到 WorkBuddy 的 MCP 配置中；保留其他连接器。如果界面分别提供名称、命令、参数和环境变量输入框，按生成文件填写对应值。

保存后启用并信任该连接器，重新加载工具列表。此包采用本地 Python stdio，不是填入一个远程 MCP URL，也不是已上架的 WorkBuddy 专家技能连接器。

## 4. 自检与首次使用

运行向导结束时打印的自检命令，或：

```sh
python3 scripts/setup_workbuddy.py --check ~/.aicheck/workbuddy/mcp.json
```

Windows 使用 `py -3` 和实际配置完整路径。自检会启动配置中的程序，只对你自己生成或信任的配置运行。

预期结果：MCP 握手成功、发现 9 个工具、后台 connection 成功。此项不会上传文件，也不能证明 OCR 令牌有效或供应商服务正常。

然后对 WorkBuddy 说：

> 使用 aicheck-data-services，实际调用 aicheck_connection，参数为 {}，报告能力及错误码。随后对我指定的 PDF 调用 ocr_submit、ocr_status、ocr_result，报告任务状态和识别页数，不据此判断工程符合性。

指定文件必须位于允许的资料目录。OCR 会发送文件至管理员配置的服务器及 MinerU 服务；原件及产物按服务器策略留存，当前包没有自动删除或固定到期清理保证。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 平台未连接，但脚本自检成功 | 确认 MCP 已启用、信任、保存到当前环境；重新加载或重启平台。Skill 已导入并不表示 MCP 已连接。 |
| Python / 脚本不存在 | 用可用的 Python 3.10+ 重新运行向导；检查解压目录是否移动。 |
| notConfigured | 检查环境变量 AICHECK_BASE_URL 是否合并到 MCP 配置。 |
| networkError | 确认后台地址可访问、HTTPS 证书有效，联系管理员检查服务。 |
| tokenUnavailable / notAuthenticated / 401 | 检查个人令牌文件路径；登录获取新令牌，保持单行文本。connection 成功并未验证 OCR 登录权限。 |
| pathNotAllowed | 将对应资料文件夹加入允许目录，再生成并更新配置。 |
| 50330 / OCR failed | 保留错误码和 jobId，联系管理员检查存储、MinerU 和任务执行服务；不要反复创建新任务。 |
| 提示配置已存在 | 使用 --output 指定新文件名，并用 --token-file 指向已有个人令牌；不会覆盖原文件。 |

## 管理员交付条件

发布包可分发，服务运营仍需管理员完成：HTTPS 地址、独立用户账号与令牌、数据库、对象存储、MinerU 供应商配置及持续运行的 worker。须部署新增的 `/api/internal/ocr/mineru/tasks/{jobId}/result` 接口，并验证跨用户任务隔离。

本机测试使用的 API 地址和 SSH 存储隧道不能作为公共服务承诺。详见 [服务器要求](references/platform-setup.md)。
