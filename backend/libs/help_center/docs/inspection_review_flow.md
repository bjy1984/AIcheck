# 节点审查流程

## 处理一个节点的完整步骤
关键词：怎么审查、流程、步骤、节点、办理、从哪开始、下一步
1. 在项目总览（勾「只看需处理」）或左侧项目树点开一个节点。
2. 看「本节点所需资料」：必传资料是否齐全、是谁提交的、是哪个版本。
3. 逐份核对资料：点「查看原文」对照原件和 OCR 抽取的字段、表格、印章。
4. 看 AI 复核给出的审查事项和证据，决定是否采纳。AI 只是辅助，不会自动成为正式结论。
5. 在「人工审查」里选审查结论、勾选引用的已确认证据、写复核意见，点保存。
6. 资料缺失、字段冲突、签章异常等问题，选「退回补正」，写明资料项和整改要求。
7. 对方补正提交后，回到同一个节点看新版本、差异说明和证据链，再次核验并保存意见。
节点页顶部的状态条把办理过程分成七项：资料提交、OCR 抽取、证据确认、AI 复核、人工结论、报告、归档，可以看到现在走到哪一项。

## 人工审查结论怎么选
关键词：审查结论、满足要求、需补正、不适用、证据不足、人工审查、保存
「人工审查」里的「审查结论」有四个选项：
- 满足要求：资料齐全且与规则要求相符。
- 需补正：已经能判断资料有问题，要求对方改正或补充。
- 不适用：该节点对本项目不适用。
- 证据不足（待补件后复核）：现有资料不够或看不清，暂时无法判断，补件后再复核。
选好结论后，在「结论引用证据」里勾选支持这个结论的已确认证据，再写复核意见。系统不会替你预选结论。

## 为什么保存不了「满足要求」
关键词：不能保存、保存失败、保存按钮灰、前置阻断、已确认证据、满足要求
常见原因有两个：
- 当前节点没有「已确认证据」：页面会提示“当前节点暂无已确认证据，不能保存「满足要求」正式结论”。先去核对资料，把能支持结论的证据确认好。
- 「正式审查存在前置阻断」：页面会列出阻断原因（例如必传资料没齐、OCR 不完整），先解决这些原因。
另外，没有选「审查结论」时保存按钮会给出“请先选择审查结论”的提示。

## 什么时候选「退回补正」
关键词：退回补正、补正、整改、退回、补件、期限
资料缺失、字段冲突、签章异常、资料版本不对时使用。退回时写清楚节点、资料项、问题、补正要求和期限。
退回后，施工方或无损检测机构会在自己的“审核反馈”入口看到，并上传替换版本、填写差异说明。你在同一个节点查看版本链、证据链和字段差异，重新核验后再保存意见。
首次提交的异常文件会保留，不会被物理删除。

## 需补正和证据不足有什么区别
关键词：区别、证据不足、需补正、选哪个
- 需补正：你已经能确定资料有问题，要求对方改。
- 证据不足：问题不在对方“错了”，而是现有资料不足以下判断（缺资料、扫描看不清、字段没抽出来），要补件后再看。
拿不准时先选「证据不足」，不要为了好看选「满足要求」。

## 上传监检自己形成的证据
关键词：上传监检资料、现场照片、见证、抽查、监检证据、上传
监检人员只上传自己在现场见证、抽查或人工评价时形成的证据（比如现场核验照片、外部查询截图）。入口：监检工作台 → 项目审核节点 → 选择对应节点 → 上传监检资料 → 选择文件 → 保存，然后核对证据状态。照片类文件没有 OCR，直接提交后由人工核验。

## R69 质量保证体系怎么处理
关键词：R69、质量保证体系、工作流执行记录、最终评价
R69 只校验工作流执行记录和人工评价材料，系统不会自动生成或覆盖质量保证体系的评价结论。R01 到 R68 全部闭环后，由监检人员在 R69 上完成人工评价。
