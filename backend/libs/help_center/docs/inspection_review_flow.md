# 节点审查流程

## 处理一个节点的完整步骤
关键词：怎么审查、流程、步骤、节点、办理、从哪开始、下一步、资料、逐条核对、审查结论、处理流程
1. 在项目总览点一行展开后点「进入节点」（或点行右边的按钮），也可以在左侧项目树点节点。
2. 看左边「资料」：本节点要的资料，标「缺」的是还没有，右上角是「必传 已交/应交」。点「挂接资料」把文件库里已有的文件挂上；缺的点「通知补正」；「资料明细与挂接」看全部资料和原文。
3. 看「逐条核对」：AI 标「AI：有问题」「AI：请你确认」的审查点，点开看依据和证据；通过的、证据不足的折叠在下面。AI 还没审或资料更新了，点「发起节点复核」。
4. 在右边「审查结论」选结论、勾「引用证据」、写「审查意见」，点「保存结论」。
5. 要退回时选「需补正」，按钮会变成「保存并退回补正」，意见作为补正要求发给施工方；也可以在逐条核对的某条下点「据此退回补正」。
6. 对方补正提交后，回到同一个节点看新版本和差异，再次核对并保存结论。
节点页底部「处理流程」展开七步：资料提交、OCR 抽取、证据确认、AI 复核、人工结论、报告复核、签发归档，可以看到走到哪一步；生成报告、签发归档也在这里。

## 人工审查结论怎么选
关键词：审查结论、满足要求、需补正、不适用、证据不足、人工审查、保存结论、审查意见
节点页右边「审查结论」有四个选项：
- 满足要求：资料齐全且与规则要求相符。
- 需补正：要施工方补交或改正，选它之后可以直接退回。
- 证据不足：现有资料不够或看不清，暂时无法判断，补件后再看。
- 不适用：该节点对本项目不适用。
选好后在「引用证据」里勾选支持这个结论的已确认证据，在「审查意见」里写判断和依据（最多 500 字），点「保存结论」。系统不会替你预选结论。

## 为什么保存不了「满足要求」
关键词：不能保存、保存失败、保存按钮灰、暂不能判、已确认证据、满足要求、必传审查点
常见原因有两个：
- 右边「审查结论」顶上提示「暂不能判「满足要求」」：仍有必传审查点缺少已确认资料证据。先在「资料」里挂接或补齐资料，确认能支持结论的证据。
- 「引用证据」下提示「当前节点暂无已确认证据，不能保存「满足要求」」：还没有一条证据被确认。
另外，没有选结论时，「保存结论」下面会提示「请先选择审查结论」。

## 什么时候选「退回补正」
关键词：退回补正、补正、整改、退回、补件、通知补正、保存并退回补正、据此退回补正
资料缺失、字段冲突、签章异常、资料版本不对时退回。有三个入口：
- 右边「审查结论」选「需补正」，写审查意见，点「保存并退回补正」；
- 「资料」里缺的那一项点「通知补正」，把缺项写进补正要求；
- 「逐条核对」某条下点「据此退回补正」。
退回后，施工方在首页「监检退回，需要你处理」的红色卡片里看到，补交资料或提交反馈；无损检测机构在「监检反馈」里处理。对方补完后你在同一个节点核对新版本再保存结论。首次提交的文件会保留，不会被物理删除。

## 需补正和证据不足有什么区别
关键词：区别、证据不足、需补正、选哪个
- 需补正：你已经能确定资料有问题，要求对方改。
- 证据不足：问题不在对方“错了”，而是现有资料不足以下判断（缺资料、扫描看不清、字段没抽出来），要补件后再看。
拿不准时先选「证据不足」，不要为了好看选「满足要求」。

## 上传监检自己形成的证据
关键词：上传监检资料、现场照片、见证、抽查、监检证据、上传
监检人员只上传自己在现场见证、抽查或人工评价时形成的证据（比如现场核验照片、外部查询截图）。入口：监检工作台 → 项目审核节点 → 选择对应节点 → 上传监检资料 → 选择文件 → 保存，然后核对证据状态。照片类文件没有 OCR，直接提交后由人工核验。

## R69 质量保证体系怎么处理
关键词：R69、质量保证体系、工作流执行记录、最终评价
R69 只校验工作流执行记录和人工评价材料，系统不会自动生成或覆盖质量保证体系的评价结论。R01 到 R68 全部闭环后，由监检人员在 R69 上完成人工评价。
