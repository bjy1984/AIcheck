# 使用教程文档（给 AI 助手检索用）

这里的 markdown 是监检人员「使用教程」的底稿，AI 审查助手的 `search_help_docs` 工具按小节检索它们来回答“怎么用”类问题。以下划线开头的文件（比如本文件）不会被检索。

## 写法约定
- 文件名前缀决定谁能检索到：`inspection_*.md` 只给监检人员，`common_*.md` 所有角色。
- 一级标题 `# ` 是文档名；每个二级标题 `## ` 是一个检索单元，一节讲一件事，正文控制在六百字以内。
- 二级标题下第一行可以写 `关键词：a、b、c`，用来补上用户可能用的叫法，检索时这些词权重最高。
- 只写页面上真实存在的名称和行为，按钮、标签的文字照抄界面。不确定的写法宁可不写——助手只会照教程回答，写错了它会把错的讲给用户听。
