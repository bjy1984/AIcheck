## 1. 使用范围与上传口径

本说明用于按照当前系统界面完成完整业务资料包测试。操作主体必须使用系统现有界面角色；不同角色从各自工作台的专属资料入口上传、维护或审查资料。**R01–R69只作为监检人员的业务节点体系，不是施工方和无损检测机构的统一上传目录。**

上传时遵守以下规则：

1. 上传源文件：DOCX、XLSX、JPG以及原生PDF按现有格式上传。
2. 由DOCX/XLSX生成的转换PDF仅用于预览、签章和结果核验，不作为默认上传件。
3. 施工照片、底片模拟图和查询截图的源文件是JPG；没有OCR文本时仍可提交，由监检人员人工核验。
4. 同一角色面对多个监检接收节点时，源文件只上传一次，通过本角色的资料项、关联审核环节或检测资料提交功能复用。
5. 已提交文件不得物理删除；异常处理使用替换版本、追加附件或补正反馈，保留完整历史。
6. 文件中的印章、签名和证书仅限测试专用合成形态，不得用于真实工程。

## 3. 测试前准备

1. 解压或保留测试资料根目录的原有分册结构，不改名、不移动分册内文件。
2. 确认系统项目名称与本说明顶部项目一致；若系统已有同名项目，使用本次测试专用项目实例。
3. 准备管理员、施工方、无损检测机构、监检人员、建设单位和FDE账号；不得跨角色共用同一登录会话。
4. 以施工方上传基础和场景资料、无损检测机构上传检测资料、监检人员上传现场证据的顺序执行。
5. 每批上传后等待文件状态进入可提交状态；OCR失败不等于照片缺失，JPG现场证据按人工核验路径继续。
6. 每个角色提交后保存提交批次号、文件版本号、操作者和时间截图或审计记录。

## 4. 系统管理员初始化

1. 进入“管理后台 → 项目立项/项目详情”，建立或选定本次测试项目。
2. 在“组织用户”中确认施工方、无损检测机构、监检单位和建设单位组织及用户为启用状态。
3. 在“角色权限配置”和“项目成员授权”中分别绑定施工方、无损检测机构、监检人员、建设单位；FDE保持技术审计权限。
4. 在“项目审核节点维护”中确认监检角色可见R01–R69；其他角色只使用各自工作台入口。
5. 分别登录六类角色验证默认工作台正确，确认建设单位只读、FDE无业务上传和审批权限。

## 6. 无损检测机构上传清单

### 6.1 通用操作与专属入口

无损检测机构从“无损检测资料库 / 检测资料台账”办理，不进入施工方项目文件库，也不按完整R01–R69树逐节点上传。R编号仅用于提交后由监检人员定位。

| 资料类别 | 界面入口和操作 | 本包执行口径 |
| --- | --- | --- |
| 机构与人员资质 | 对应类别“上传资料” | 上传基础无损检测综合源文件；其中的机构、人员和任命信息供监检核验 |
| 检测方案与工艺 | 对应类别“上传资料” | 复用已上传的综合源文件和专项检测报告中的方案/工艺页，不重复上传同一源文件 |
| 检测设备与校准 | 对应类别“上传资料” | 复用综合源文件中的设备与校准页；在资料项中标识设备/校准用途 |
| 底片与影像资料 | “新增底片编号”→登记焊口关系→“上传底片/影像” | JPG模拟底片和现场图无OCR也可提交 |
| 检测记录 | “批量导入记录”或“上传检测记录” | 维护底片号、焊口号、管线号、方法、日期、评定级别和报告号 |
| 检测报告 | “上传检测报告” | 填写报告号、委托号、方法、比例、标准、人员、结论；RT报告必须关联底片 |

### 7.2 监检审查动作

1. 在R节点中核对资料项覆盖、来源角色、文件版本、OCR/结构化字段和关联审核环节。
2. 需要自动复核时发起“重新核验/AI复核”，但最终业务结论仍由监检人员保存。
3. 资料缺失、字段冲突、签章异常或预置场景异常时执行“退回补正”，写明资料项和整改要求。
4. 补正提交后查看新版本、差异说明和证据链，再次核验；不得覆盖或删除首次异常证据。
5. R69只校验工作流执行记录和人工评价材料，系统不得自动生成或覆盖质量保证体系评价结论。

## 11. 异常、补正与最终合格闭环

### 11.1 统一闭环步骤

1. 原角色提交预置异常源文件，监检人员在对应R节点确认异常被识别。
2. 监检人员点击“退回补正”，写明节点、资料项、问题、补正要求和期限。
3. 原上传角色从本角色的“审核反馈/问题处理闭环”入口打开反馈。
4. 上传替换版本或补正附件，填写差异说明；已提交异常文件保留，不物理删除。
5. 提交补正反馈；监检人员在同一R节点查看版本链、证据链和字段差异。
6. 重新核验并保存人工意见，节点状态更新为合格/关闭。
7. R01–R68全部闭环后，由监检人员完成人工R69评价；建设单位验证最终只读状态。

### 11.2 必测异常场景

| 场景 | 首次异常 | 补正资料/动作 | 最终判定 |
| --- | --- | --- | --- |
| S02 材料代用 | 原材料与代用材料、设计批准或WPS适用性出现差异 | 施工方补充批准文件、校核和适用性资料，重新关联审核环节 | 代用审批链和技术条件一致，合格关闭 |
| S03 焊缝返修与热处理 | 首次无损检测报告含不合格焊口 | 施工方提交返修方案/记录；无损检测机构提交复检合格报告；热处理资料补齐 | 返修、复检、PWHT和硬度全部合格 |
| S06 耐压免除或替代 | 耐压免除/替代条件或审批资料初次不完整 | 施工方补充论证审批与替代试验；无损检测机构补充100%检测报告和底片 | 替代条件成立、措施执行、最终确认合格 |
