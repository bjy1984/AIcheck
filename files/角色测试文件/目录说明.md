# 角色测试文件目录说明

## 1. 使用方法

本目录是 `R01-R69全节点业务验收测试包` 的角色选件副本区。测试人员应先登录界面角色，再从该角色对应的本地目录选择清单指定的源文件上传。

角色目录中的 DOCX、XLSX、JPG 和原生 PDF 均为实际复制的源文件；原完整资料包仍是权威来源且保持不变。DOCX、XLSX转换形成的同名 PDF 只用于预览、签章和结果核验，不作为默认上传件，也未复制到本目录。

## 3. 各角色从哪里选择文件

### 3.1 施工方

1. 登录“施工方”。
2. 打开“施工方工作台 → 项目文件库 / 施工资料台账”，进入清单指定的资料类别。
3. 在本地打开 `files/角色测试文件/02_施工方/<资料类别>`，选择[施工方上传清单](02_施工方/上传清单.md)同一行列出的源文件。
4. 上传后选择资料项和关联审核环节，再提交。

施工方不按 R01–R69目录逐节点找文件；R编号只是提交后供监检人员定位的预期接收范围。

### 3.2 无损检测机构

1. 登录“无损检测机构”。
2. 打开“无损检测工作台 → 无损检测资料库 / 检测资料台账”，按清单执行“上传资料”“新增底片编号”或“上传检测报告”。
3. 在本地打开 `files/角色测试文件/03_无损检测机构/<检测分类>`，选择[无损检测机构上传清单](03_无损检测机构/上传清单.md)同一行列出的源文件。
4. 维护底片、焊口、报告等结构化关系，按授权范围提交检测资料。

没有独立源文件的检测方案、设备、记录和问题闭环目录提供操作说明；按说明复用已上传源文件或在界面形成结构化记录，不重复上传同一文件。

### 3.3 监检人员

1. 登录“监检人员”。
2. 打开“监检工作台”，进入[监检人员上传清单](04_监检人员/上传清单.md)指定的 R 节点。
3. 在本地打开 `files/角色测试文件/04_监检人员/<R节点目录>`，选择该目录内的现场照片、查询截图或 R69 评价记录。
4. 使用“上传监检资料”提交；JPG没有 OCR 信息时直接提交并人工核验。

施工方和无损检测机构提交的资料由监检人员在 R01–R69节点审查，但不应从监检人员目录重复上传。

## 4. 清单入口

- [测试控制文件清单](00_测试控制资料_不上传/文件清单.md)：12份，只核对、不上传。
- [施工方上传清单](02_施工方/上传清单.md)：44份，按十类施工资料选择。
- [无损检测机构上传清单](03_无损检测机构/上传清单.md)：8份，按检测专属入口选择。
- [监检人员上传清单](04_监检人员/上传清单.md)：12份，按实际监检节点选择。

完整界面操作顺序、R01–R69接收关系、S01–S06条件场景和异常闭环见 `files/测试说明.md`。

## 5. 异常到最终合格闭环

首次异常文件不要在本地删除或覆盖。按清单顺序提交异常资料，界面退回后，再从同一角色目录选择返修、补正、复检或最终确认源文件，以新版本或补充附件重新提交。监检人员复核合格后完成 R69评价，最终所有节点均应合格闭环。
