# 新旧方案对比总表（全部为本轮实测，非推演）

- **旧** = 现在生产在跑的：大模型写自由文本发现 + 子串匹配校验主张。
  数据来自 P-2026-ECD202 全部 223 次 `review_runs`、1 038 条发现。
- **新** = 大模型拆主张 + Jev 逐条核；原子项结论由 Jev 三态作答。
  数据来自两轮影子运行（222 格 / 635 题 ×2）、主张验证（238 条）、拆题（60 条发现 → 297 主张）。

裁决层（186 项确定性工具）两边都不动，不在对比范围内。

## 一、抓错能力

| | 旧 | 新 |
|---|---|---|
| 校验方式 | 子串匹配：发现里的词有没有在证据里出现 | 语义核对：这条主张资料支不支持 |
| **编造的数值能否抓出** | **0 / 6** | **6 / 6** |
| 含编造串的发现 | 11 条，其中 8 条「不支持主张」栏全空 | 逐条标出，信心 0.77–0.99 |
| 这些发现当时的状态 | 标为 `grounded`（通过了证据落地校验） | — |
| 校验产出的形状 | 1 417 条「主张」，其中 640 条 ≤6 字碎片（`许可证` 101 次、`有效期` 58 次） | 命题级主张，可独立判真假 |

典型：节点 25 的发现声称「查到电流范围 GTAW 110-120A/SMAW 120-130A、电压 10-15V/25-30V」，
这四组数值在 `9.1金辉焊接工艺评定20.pdf` 全文里一个都不存在。旧方案没察觉，新方案信心 0.99 标出。

## 二、可复现性

⚠️ **两边量的不是同一个单位，不能直接相减。**
旧量的是自由文本发现集合的重合度（题目每次都不同）；新量的是同一道固定题两次作答是否相同。

| | 旧（145 对同输入运行） | 新（635 题跑两轮） |
|---|---|---|
| 内容一致 | 软一致率 **0.51** | 同一答案 **97.5%** |
| 完全对不上 | **50 / 145 = 34%** | — |
| 高信心部分 | 无此概念 | **0.50 以上 514 题零翻转** |
| 会自动采纳的部分 | 无此概念 | **429 题，两轮 100% 相同** |
| 节点级结论一致 | 81%（来自确定性层，非大模型） | — |

翻转的 16 题全在信心 0.50 以下，其中 14 条是「证据不足 ↔ 需人工」互换，两个都转人工。

## 三、不确定度与分流

| | 旧 | 新 |
|---|---|---|
| 有没有校准过的信心 | 无。`confidence` 是引用覆盖率，量「引了多少」不量「对不对」 | 有，每题带完整机率分布 |
| 信心分布 | 92% 低于 0.7 | ≥0.90 占 50%，≥0.70 占 68% |
| 能否给人工排队 | 不能 | 能：不一致 + 低信心排前面 |
| 小标注集上的准确率 | 未量过 | 12 条里 conf ≥0.70 的 9 条全对；两个错全在 0.70 以下 |

## 四、与确定性层的关系

| | 旧 | 新 |
|---|---|---|
| 逐项对照 | 不可对照（自由文本，无三态） | 85 题可对照，**一致 81%** |
| 自信分歧 | — | **1 题**（且是「证据不足↔需人工」，轻微） |
| 抓到确定性层的错 | 否 | 是：节点 3 的 `verified_mismatch` 误报（公司名在文中出现 7 次且与平台一致，坏的是抽取字段） |

## 五、成本与速度

| | 旧 | 新 |
|---|---|---|
| 每节点 | 一次大模型调用 | 一次 Jev 调用 ≈ **$0.0002** |
| 七项目全扫 | — | **$0.027**，两分多钟 |
| 单次延迟 | 分钟级（含 OCR、检索） | **1.1 – 2.1 秒** |
| 多问几题 | 更长的文本、更贵 | 几乎免费：1 题 2 071ms / 12 题 1 384ms |
| 解释生成 | 每条发现都写 | 只对分歧/未通过写 —— 费用下降的主要来源 |

## 六、各自的硬限制

| | 旧 | 新 |
|---|---|---|
| 上下文 | 分片（EvidenceShard），无本地上限 | **约 32 800 token ≈ 53 000 字**；223 格里 2 格超限 |
| 取外部数据 | 大模型可被动接收检索结果 | 不取数；给了平台数据判得准（0.96），不给就瞎猜（0.36） |
| 产出引文页码条款 | 大模型写（可能是编的） | 支持页题可指页；条款仍需大模型/检索 |
| 结论随版本漂移 | 有 | 固定 `jev-1.13.0` 可复现 |
| 资料是否出境 | 否（百炼国内端点） | **是（美国西岸）** |
| 识别跨工程串资料 | 否 | 否（节点 29 用姜军的证判了通过 0.56） |

## 七、实测出的新风险

| 风险 | 猜测 | 实测 |
|---|---|---|
| 大模型拆题不忠实（凭空捏造编号） | 担心 | **0 / 238 = 0%** |
| 主张框得有歧义 | 担心 | 1 条 |
| Jev 用逃生门逃避作答 | 担心 | 5 条（2.1%），且用得对 |
| **注入的事实自相矛盾 → 自信答错** | 没想到 | **发生了**：节点 1 的 3 条，信心 0.77–0.79 |

根因是 `AC-R01-02` 与 `AC-R01-03` 对同一份资质给出相反判定，Jev 采信了错的那条。
**结论：注入 state 的「已核实事实」必须先自洽，否则新方案会放大上游的错。**

## 九、不可比与未验的，写在这里免得被当成结论

- 第二节两边单位不同，只能各看各的趋势。
- 238 条主张里只有 12 条不一致经过人工逐条裁定，其余 226 条未逐条验真。
- 人工裁定是我做的，不是监检做的。
- 全部数据只来自 ECD202（主张验证）与七个项目（原子项影子运行），量级不可外推。
