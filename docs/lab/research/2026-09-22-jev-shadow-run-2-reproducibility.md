# Jev 影子运行第二轮：同输入复现率

同一份 `data.json`、同一套题、同一模型版本 `jev-1.13.0`，跑第二遍。
两轮各 222 格、635 道三态题 + 635 道支持页题，两轮都成功的题 **1 270 道，无缺失**。

## 一、结果

| | 三态题 | 支持页题 |
|---|---|---|
| 两轮同一答案 | **619 / 635 = 97.5%** | 628 / 635 = 98.9% |
| 机率漂移中位数 | 0.010 | 0.000 |
| 机率漂移 p90 / 最大 | 0.040 / 0.200 | 0.040 / 0.200 |
| 完全不动（漂移 < 0.01） | 44% | 68% |

**按第一轮信心分桶的翻转率：**

| 信心 | 三态题数 | 翻转 |
|---|---|---|
| ≥ 0.90 | 320 | **0** |
| 0.70 – 0.90 | 112 | **0** |
| 0.50 – 0.70 | 82 | **0** |
| < 0.50 | 121 | 16（13.2%） |

**0.50 以上的 514 道题，一道都没翻。** 全部 16 个翻转集中在最低信心桶。

节点级：222 个格里，**206 个（93%）全部原子项两轮答案完全一致**。

## 二、翻转是什么性质的

16 个翻转的方向：

- `evidence_insufficient` ↔ `human_review_required`：**14 个**
- `human_review_required` ↔ `passed`：2 个（信心 0.12 → 0.19，两轮都远低于阈值）

这两种方向**都转人工**。没有一个翻转改变了「这件事成立与否」的判断方向，
也没有一个把「不成立」翻成「成立」进了自动路径。

## 三、按方案的 0.70 阈值分流之后

分流规则：`confidence ≥ 0.70` 且结论不是 `human_review_required` → 自动；其余转人工。

| | |
|---|---|
| 第一轮走自动路径 | 429 题（68%） |
| 其中第二轮答案相同 | **429 / 429 = 100%** |
| 两轮都 ≥ 0.70 的题 | 427，答案一致 **427（100%）** |
| 两轮「自动/人工」归属不同 | 8 题（1.26%） |

那 8 题全部是**同一个结论**（都是 `evidence_insufficient`），只是信心在 0.65 – 0.72 之间
抖过了 0.70 这条线。**结论没变，只是这一次被标去人工复核、下一次没有。**

也就是说：**自动路径上没有出现过一次结论变化。** 波动只发生在「要不要提醒人看」这一层，
且集中在阈值附近 ±0.05。

## 四、和大模型基线怎么比（口径要说清楚）

大模型那边量到的 0.51 软一致率、34% 完全不重叠，量的是**自由文本发现集合**的重合度——
题目本身每次都不一样。这里量的是**同一道固定题**两次作答是否相同。
**两个数不是同一件事的两次测量，不能直接相减。**

能说的是：把决定拆成固定题之后，决定层的波动从「每次问的问题都不同」变成
「0.50 以上一题不动，0.50 以下 13% 在两个都要转人工的选项间抖」。
方案里「原子项锚定消除出题波动」这一条，得到了支持：题固定住，答案就基本固定住了。

**仍未量到的**：大模型出增量题那一路的复现率。那部分题目由大模型生成，每次会变，
本轮没有测到。那是接入大模型发现层之后要单独量的。

## 五、对阈值的建议

- 数据支持把阈值放在 **0.50**（0.50 以上零翻转），但 0.50–0.70 这一段的**准确率**没有标注集支撑，
  不能只因为稳就自动采纳。**阈值定在哪要等人工标注，不能用复现率代替准确率。**
- 阈值附近的抖动（±0.05）会让 1.26% 的题在两次运行间改变人工队列归属。
  若要稳定队列，可用滞后区间：进队列 < 0.68，出队列 ≥ 0.72。
