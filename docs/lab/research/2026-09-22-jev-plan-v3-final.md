## 三、架构（与 v2 相同，多一条硬约束）

```
OCR → [新 A] 表格行角色分类 → 事实构建 → run_rule_engine（确定性，裁决权不变）
                                              │
                                    ┌─────────┴─────────┐
                                    ▼                   ▼
                        [新 B] 全量第二意见      大模型写发现
                        每原子项三态+支持页              │
                                    │          [新 C] 拆成主张 → Jev 逐条核
                                    │                   │
                                    └────────┬──────────┘
                                             ▼
                        一致且 conf ≥ 0.72 → 照旧，标「第二意见一致」
                        不一致 / conf < 0.68 / 主张被打回 → 人工队列前排
                        解释只对进队列的生成
```

**v2 之后新增的硬约束（实测逼出来的）**：

> **注入 state 的「已核实事实」必须先自洽。**
> 节点 1 的三道题 Jev 自信答错（0.77–0.79），根因是我喂进去的两条 check 互相打架
> （一条说许可范围覆盖 GC2、满足，一条说不覆盖、不满足）。
> **它是判断者不是查证者，上游错了它会放大。** 组装 state 前必须做一致性校验，
> 发现矛盾就不注入，只给资料原文。

其余约束沿用 v2：固定 `jev-1.13.0`；只给整节点全文不给片段；多人文件按人拆题；
异步不进同步路径。阈值改用滞后区间 **进队列 <0.68 / 出队列 ≥0.72**
（实测 1.26% 的题在 0.70 附近抖动会来回改变队列归属，结论并没变）。

### 第 3 期 · 表格行角色分类进生产（第一个真正上线的点）

位置：`r13_facts.py` 的 `_row_quote` / `_has_business_content` 之前。
每张表问两题：这张表是什么（力学性能/WPS参数/焊工证/材质单…）、每行是什么角色

守卫：环境变量开关；不可达或 conf < 0.90 回退现有正则；沙箱测试用录制响应不打外网。
验收：七项目扫描前后对比，节点 25/29/32 的 71 条假事实应消失。

### 第 4 期 · 主张核对接进发现层

大模型写完发现 → 拆成主张（实测 60/60 成功、忠实度 100%）→ Jev 逐条核 →
被打回的主张不进结果，整条发现降级为待人工。

这是**抓错收益最大**的一期（编造数值 6:0），但也是改动最深的一期，
放在表格分类稳定跑一段之后。

### 第 5 期 · 第二意见与人工排队进界面

`review_run` 增 `secondOpinion: {choice, confidence, model, agreesWithRuleEngine}`；
界面每行加「第二意见一致 / 分歧，建议人工」；队列按 分歧 > 低把握 > 其余 排序；
`llm_generate_findings` 改为只对进队列的生成解释——**这是费用下降的那一刀**。

### 第 6 期 · R19 的 8 项语义题

现在是自由文本，换成三态+把握值。范围小，单独一期便于看效果。
