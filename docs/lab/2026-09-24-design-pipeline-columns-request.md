# 請設計方在管道特性表補三欄

2026-09-24　｜　Lab 分支　｜　口徑已確認

## 為甚麼需要

R47 靜電接地、R66 泄漏試驗條件、R67 泄漏試驗方法是否適用，由介質的危害性決定。口徑已經確認：

- R66／R67：介質**有毒**或**有泄漏危害性**時適用；
- R47：介質**火災危險性為甲、乙類**（或寫明可燃、易燃）時適用；
- **只看設計資料明寫的欄位**，不按介質名稱推斷，也不另建介質危害對照表（2026-09-24 決定）。判不了就維持「證據不足」，由監檢員人工確認。

目前七個項目的管道特性表（設計說明書、設計圖紙、壓力管道匯總表）都沒有這三欄，所以這三條規則在這批資料上一律判不了適用性。

## 請補的欄位

在管道特性表（或管道數據表、壓力管道匯總表）每條管線一行，加上：

| 欄名（請照寫） | 填什麼 | 系統認得的寫法 |
|---|---|---|
| 毒性程度 | 介質毒性危害程度（GB/Z 230） | 極度危害、高度危害、中度危害、輕度危害、有毒、劇毒；無毒寫「無毒」 |
| 泄漏危害性 | 是否為泄漏危害性介質 | 泄漏危害性、易泄漏；不是寫「無」 |
| 火灾危险性 | 火災危險性類別（GB 50160） | 甲A、甲B、乙A、乙B、丙A、丙B（或甲類、乙類）；可燃、易燃 |

- 欄名也接受：「介質毒性」「泄漏危害」「火灾危险类别」「火灾危险性类别」。
- 空著、寫「待確認」「不詳」，系統都當成判不了，不會當成「不適用」。
- 管線號請與施工記錄一致；記錄上的「-100」等尾碼按公稱直徑處理（已確認），設計表寫不帶尾碼的管線號也能對上。

## 收到新樣本後

新版式的表頭要照真實樣本逐字寫進簽名（`table_schema_signatures.yaml` 的 `pipeline_characteristics` 或 `pipeline_summary`），不能憑這份說明預先寫，否則會在真實資料上配錯表。收到帶這三欄的設計文件後：

1. 把表頭逐字加成新的版式；
2. 在快照上重放所有可重放的規則，逐條核對 R47／R66／R67 的適用性和其餘結論的變化。
