# AICheck 工位制實驗分支

分支：`codex/lab-aicheck-workstations`，基於修復分支 `9bfb6f3`。本分支實作整合計畫，不以建立分支或 A 工位原型作為整體完成。

## 既定契約

- A 焊接 R24–R34；B 設計 R01/R04–R10/R63；C 施工品質 R02/R11/R69；D 材料 R12–R23；E NDT R03/R35–R42/R65；F 防護 R43–R47/R50；G 安裝 R48–R49/R51–R55；H 安全附件 R56–R58；I 系統試驗 R59–R62/R64/R66–R68。
- 每個節點只有一個主責工位；每次模型請求一個角色、一個節點。O 協調者無業務判定權。
- 自動核對＋可追溯人工見證；缺資料不假定不符合，文件存在不等於符合。
- 自由選取有權存取的已上傳文件，預設僅本次，可保存節點掛載；解除掛載不刪文件，固定文件版本與範圍。
- 自由編輯業務規則，預設工程專用草稿；描述、適用性、資料要求、原子項、限值、依據及協作要求皆可修改。試跑比較後發布，prompt 與工具共同使用同一份有效規則。
- 工程與平台規則隔離；自然語言生成草稿，未支援的條件不得冒充可執行判定。
- 新任務固定所有版本，歷史結論不改寫；交接包含工程、對象、節點、文件版本與證據，上游變更僅觸發相關下游待重驗。

### 完整後端回歸啟動方式

與 backend-quality CI 相同，從 backend 工作目錄執行：

```sh
cd backend
.venv/bin/python -m pytest tests --collect-only -q
.venv/bin/python -m pytest tests -q --tb=short
```

倉庫根目錄與 backend 各有 scripts/openapi_contract.py；從倉庫根目錄直接執行後端 pytest 曾載入後端同名模組，導致 OpenApiContractError 匯入失敗。這是啟動路徑問題，不能把收集失敗視為測試通過。完整結果與服務整合環境分開記錄。
