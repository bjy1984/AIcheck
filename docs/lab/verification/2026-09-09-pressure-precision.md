# 試驗倍率限值精度（2026-09-09）

原問題：R09 design_special_requirements 將試驗壓力／設計壓力先 round(..., 3)，造成 1.4996 變 1.5，1.3304 變 1.33，可能隱藏未達下限或超上限。

新增 pressure_ratio_calculation，以 Fraction 精確表示來源十進位及商值後比較，下限／上限判定不經浮點顯示值；輸出的 testPressureRatio 沿用數值型別，僅供呈現，不再反過來控制判斷。原始試驗壓力文字直接傳入。分母只接受有效正數，布林／NaN／無限／非正值不再採用。限制輸入長度及指數長度，拒絕非十進位分數字串與巨大指數，非法值不回退另猜。

117 項相關測試通過，包括 23 個精度／輸入情境與來源到既有 evaluate_design_special_requirements：1.4996 未達下限為 failed，1.5 基礎下限測試維持 passed；2.4／1.6 不受浮點誤差影響；氣壓 1.3304 的 exceedsMax 為 true。另驗證顯示浮點即使為 1.5，精確判定仍可為 false。Ruff 289／289、monolith／diff 通過。
