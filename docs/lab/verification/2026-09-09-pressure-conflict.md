# 試驗倍率與絕對壓力矛盾（2026-09-09）

原問題：同時提供倍率與絕對試驗壓力時，計算器優先採用倍率，未檢查它是否等於試驗壓力／設計壓力。另有通用「試驗壓力」正則會匹配泄漏／氣密試驗壓力，污染耐壓資料。

新增精確來源數值一致性比較：當倍率、絕對壓力及唯一有效設計壓力齊全而不一致時，pressureRatioConflict=true，倍率判定保留未知，不選其中一筆。數值均保留於原始資料／事實；2.4／1.6 與1.5相等，極長小數不被顯示精度掩蓋。缺少對象或資料時不宣稱已確認一致。

排除泄漏、氣密性、氣密前綴，這些壓力不再充作耐壓試驗的絕對壓力。140 項壓力／設計／業務工具測試通過，包含7個新增源矛盾及領域分離情境；實際業務工具將矛盾保持 evidence_insufficient。Ruff 289／289、monolith、diff 通過。

未重跑全量；最近完整回歸仍4835通過／75跳過。仍待逐事件多管線映射、完整適用條件、OCR來源與真實案例驗收。合併文本含多個同類試驗記錄時仍需結構化逐對匹配，不能以本次衝突檢查替代完整覆蓋。整體工程估算維持約60%。
