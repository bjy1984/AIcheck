# 真實 RT 報告：同格換行編號

## 實作

既有 OpenCV 子程序升為 opencv-grid@3，新增封閉輪廓儲存格，保留原全域網格與其他欄位。全域 x/y 網格會把局部合併格切開，因此新欄位抽取只使用實際封閉輪廓，而不靠文字列表的相鄰順序。

`ndt_table_fields.py` 接入原 RT／UT 明確字段處理入口：找到唯一「報告編號／報告號」標籤格及右側唯一相鄰格，只拼該格完整包住的垂直文字行。低置信度、越界、同一行多值、座標變換、原表格 bbox 已變、重複相鄰格或非編號字元都不採用。閉合格數量超過上限時清空候選並留診斷，不以截斷清單猜唯一格。

保留每段 `sourceFragments`、來源表格／單元格 ID、實體頁碼、bbox 及最低置信度。合併字段帶 `layout_join_requires_source_review`；不改原 fragments、不生成事件身份或人工驗證。已有不同報告號保留並標記衝突，不覆蓋。

## 真實文件執行

來源：`test2/9.1金辉焊接工艺评定20.pdf` 第 11 頁；此前已檢視原圖。PyMuPDF 180 dpi 圖像為 1490×2105，實際執行 OpenCV 子程序找到 195 個封閉格。Apple Vision 原 observations 沿用前次保存結果，normalized bbox 按實際圖像大小還原 pixel，沒有調用付費模型。

原處理入口讀到 `2023SHZH-022RTBG-01`，由同格的 `2023SHZH-0` 和 `22RTBG-01` 組成，沒有夾入旁邊的承包單位。結果和全部封閉格保存在 `2026-09-09-rt-closed-cell-result.json`（省略舊全域網格 cells，原結果不受影響）。
