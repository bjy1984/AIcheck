# R11 參數比對：所選來源與未讀頁面

## 發現與修正

R11-02 原有同對象參數／完整清單工具，但事實組裝只驗參數表及引用版本，沒有逐項核對其他已選來源的解析唯一性或 OCR 覆蓋缺口。即使其他所選頁尚未讀完，局部相同參數仍可能輸出 passed。

新增 `source_coverage.selected_source_issues`，逐個已選版本驗同租戶版本、同工程文件及唯一解析結果，沿用既有頁碼範圍裁切與 review_coverage_gap。身份缺失／重複時不生成 R11 判定輸入；已知頁面缺口則傳入工具 selectionIssues，保留可確定的比較結果。

- 有所選頁缺口時，局部 passed／not_applicable 降為 evidence_insufficient，coverage.complete=false。
- 已讀到可信參數差異仍為 failed，缺頁訊息與差異同時保留。
- 身份有歧義時，既不能判一致也不能據此判差異。
- 缺頁確定在使用者選定範圍之外時不擴大審查範圍；缺頁位置未知則仍阻擋。
- 未選文件的缺口不拖入本任務。歷史缺覆蓋 metadata 的來源保持原契約，不能因此聲稱已證明整份 OCR 完成。

清單與單對象工具版本分別升為 r11-project-parameter-inventory-v2／r11-project-parameter-comparison-v2。既有 API、原子項綁定及判定碼不變，歷史快照不重寫。
