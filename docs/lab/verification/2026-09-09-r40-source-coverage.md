# R40 選定資料完整性

R40 事實組裝現會逐個核對選定版本的工程、租戶、文件與解析結果唯一性。重複版本／文件／解析或未解析的選定版本會阻止建立可判定輸入，避免第一筆資料遮蔽歧義；這種歧義也不能支持不符合結論。

對唯一、已選範圍的解析結果沿用 review_coverage_gap。若仍有未辨識頁，selectionIssues 會保留版本、頁碼與位置是否已知。專用工具不得因已抽出的表格互相一致而判完整；可追溯資料中已確認的引用不一致仍保留 failed。範圍外的缺頁不影響本次選定範圍，未知位置不能被排除。範圍外報告表不會進入本次核對，未選文件不擴大任務範圍。

40 項相關測試通過，包含有快照的頁碼範圍、缺頁／未知位置、重複版本／文件／解析、缺解析、排除報告頁、已知不符合保留與無關文件排除；R39 缺頁與資產生成回歸通過。Ruff 289／289，monolith 通過。

測試仍是標準化表與覆蓋 metadata 的合成案例，不是實際 PDF 的 R40 全流程。檢測參數、設計要求、報告結果及原文適配尚未完成，發布阻擋保持。完整輸出：r40-source-coverage.txt。
