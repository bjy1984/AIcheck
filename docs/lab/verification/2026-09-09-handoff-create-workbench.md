## 實際操作

1. 原工作台節點35→工位交接→發起工位交接。接收清單有A工位節點24的HANDOFF-SOURCE任務。
2. 選接收任務，填焊口UI-HANDOFF-W1、事件UI-EVENT-20260909、返修0及協作問題；未附引用。
3. 返回後重新打開，問題及所選任務保留。首次自動化在關閉動畫完成前連續點擊沒有重新打開，重新讀取畫面後再點即可打開，未推定資料遺失。
4. 建立草稿後成功提示：接收方可在節點24核驗，尚未作判定依據。
5. 切換節點24→工位交接，收到E→A的相同對象／事件草稿。展開核對內容一致、狀態待核驗、無引用提示、人工核驗入口可見。
6. 下次使用入口顯示尚無有效人工核驗，不能使用。未操作虛假的證據確認，也未觸發審查。
