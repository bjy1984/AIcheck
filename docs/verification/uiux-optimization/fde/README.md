# FDE 截圖問題優化與驗證

保留上一輪 `../../page-captures/fde` 原始證據，本輪圖片見 [manifest.json](manifest.json)。已逐張目視16個FDE主路由，另補規範索引與項目評估子視圖。FDE採1280×720內嵌瀏覽器，原始JPEG未加工；內部捲動頁使用首屏與內容補圖。

已確認及修復：

- 評估報告沒有樣本數、比例或布林檢測結果時，顯示「未提供」，不填0或推定通過。錯誤率缺值不再滿足低錯誤率發布門禁；缺失比例門禁標為未知並說明先取得報告。真正數值0仍保留。
- 失敗計數使用全部已失敗結果，不受原先前8筆截斷影響；空結果顯示「暫無樣本結果」，不暗示已完成且零失敗。
- 規範零切片檔案顯示「未檢測」，未向量化不因缺口0而變成成功色。全域「生產可用」必須同時有已完成檔案、非零切片、相等向量及明確零問題／零缺口。
- 能力組合、發布、回饋和事故等已知狀態改用中文；能力差異改用中文組件名，缺少基線明示未提供。發布影響的「審查任務編號」修為「審查任務數」，影響提示不把缺值轉為0/NaN。
- 項目評估與審查品質的密集雙欄表在一般桌面寬度上下排列；截圖確認1280寬度可同時閱讀門禁、實際值、目標、狀態與處理建議。側欄次要提示正常省略，完整提示可懸停查看。

`fdeReportedData.test.ts` 覆蓋缺值/空字串/布林/非法數字不轉零、實際0、比例門禁、布林三態、零切片、已完成索引、向量缺口與全域索引一致性。整合123個前端測試檔全部通過，型別檢查通過，production建置與靜態操作性檢查通過。

限制與後續：

- 截圖使用真實API與隔離記憶體示例；不代表正式資料庫、OCR、模型、發布或寫入流程驗收。審查編排缺少實際任務，空狀態已確認，未捏造執行結果。
- 規範索引等欄位很多的清單仍需要橫向捲動；本輪已改善重點雙欄表格，未宣稱所有寬表都無捲動。
- OCR未配置服務地址的診斷文案仍存在重複術語；已保留可見警告並列為低優先文字整理項。
- 首輪與最後建置之間只補強空樣本徽標及剩餘狀態欄；相關評估/事故畫面以最後建置重拍，其餘沒有變動的介面保留已檢視證據。
