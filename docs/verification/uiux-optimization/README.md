## 範圍與剩餘問題

這是目前工作區的production UI、真實API、隔離記憶體示例資料驗證。未連線正式資料庫、模型、OCR或執行正式寫入／發布；不以空狀態取代端到端流程驗收。標準PDF在Chrome確實顯示1/129頁；IAB白區與瀏覽器呈現差異有關，不能一概說缺檔或宣稱已修復所有PDF渲染。

本輪保留的低優先問題：審查點篩至0筆後舊tooltip偶有殘留；部分非重點寬表仍需橫向捲動；業主歸檔類型仍有英文代碼換行；OCR診斷文字有重複術語。發現詳情是否隨不匹配篩選保留，現有單筆示例不足以重現，仍待確認。

業務包名稱與domainType的配置語意衝突、舊legacy證據無法從節點證據API精確解析、項目原文NOT_FOUND及canonical未生成屬實際資料／服務狀態；本輪如實提示，未改seed或放寬權限掩蓋問題。
