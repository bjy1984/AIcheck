# 管理與知識庫角色內容審計

依實際路由、元件綁定、既有截圖與操作入口判斷內容用途；本輪只調整呈現，保留配置、授權、發布、回滾、上傳、重試及查閱能力。

| 範圍 | 已確認的干擾 | 處理 | 保留依據 |
| --- | --- | --- | --- |
| 管理各頁 | 頁首同時出現項目數、規則待發布、上次審計篩選數；未載入的規則／審計顯示「未取得」，與當前工作無關 | 移除全局統計。規則發布提示僅留在規則頁 | 待發布規則在規則列表可處理，審計數在審計頁查詢 |
| 管理各頁 | 「配置摘要」「配置摘要與統計」及平台職責邊界重複顯示權限／字段映射／模板數等 | 移除無關抽屜、每頁重複統計及平台邊界區塊 | 管理員專用配置、權限及審計頁的真實欄位保留 |
| 管理總覽 | 「當前治理對象」「配置影響範圍」「未取得審計」大卡不能幫助當前項目操作 | 改為項目、組織、帳號的可讀概況 | 管理員的核心維護對象，數值仍由已載入管理總覽返回 |
| 知識庫各頁 | 全局向量任務、切片配置、Embedding、TopK、索引版本和治理摘要反覆出現 | 移除全局運行抽屜和職責邊界；頁首只保留實際失敗任務的處理入口 | 失敗任務可點擊進任務中心；專業配置仍在配置頁編輯 |
| 知識庫總覽 | 首屏被治理總分、評分域、檢索探針、路由、PageIndex未取得佔滿，知識庫／來源列表需要向下尋找 | 專業評分與探針移至配置頁預設收合的「索引診斷」；總覽直接呈現庫與來源 | 診斷仍可用於配置排障，不再佔據日常資料維護首屏 |
| 知識庫索引 | 每庫直接展示切片／向量原始記錄及內部索引版本，干擾查找可用庫 | 原始記錄比較與版本改為每庫「查看記錄數量」按需展開 | 狀態、文件數、更新時間與重建操作預設可見，保留實際比較能力 |
| 標準／項目文件 | 狀態旁又附切片數、向量數，與同列處理狀態重複 | 移除列表附帶的原始數量 | OCR／切片／向量狀態用於定位處理失敗及重試，仍完整保留 |
| 知識網絡 | Header重複節點數、關係數與當前顯示數，並突出Schema與業務包版本；選中節點先顯示內部ID及英文metadata | Header計數與版本徽章移除；技術屬性改按需展開；描述改為查關係、追溯依據 | 圖表範圍數仍在圖標題；節點業務名稱、狀態、描述與關係預設可見；技術信息在主動開啟的網絡信息／屬性中保留 |

## 不應移除的專業內容

- Prompt、規則、字段映射、發布差異：管理員在指定配置頁需要維護，不因它們是技術名詞而刪除。
- 索引任務狀態、失敗重試、處理結果：知識庫管理員判斷資料能否檢索的直接依據。
- 檢索測試、推理記錄、多模型對比：由使用者主動進入的專業驗證頁，保留記錄與診斷欄位。
- 風險確認、刪除提示、發布影響範圍：影響使用者決策，保留在發生操作的地方。
