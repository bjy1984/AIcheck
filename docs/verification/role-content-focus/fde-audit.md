# FDE 角色內容審計

FDE 的工作是診斷 AI／OCR 執行、品質改善、樣本評估、版本發布、成本與安全治理。這些專業頁的指標本身是工作資料；本輪不因其技術性而刪除，優先移除與當前任務無關、重複或把內部實作暴露給操作者的內容。

| 頁面／內容 | 處理 | 判斷依據 |
| --- | --- | --- |
| 所有專頁固定顯示全局項目、審查任務、阻斷、待審批數字 | 僅治理總覽保留 | 在成本、安全、發布等工作時不反覆展示無關領域數量；全局情況仍可回總覽查看 |
| 各專頁右側固定含全局、Agent、OCR與職責四組摘要 | 改為當前頁摘要 | 總覽保留全局；審查編排只保留目前流程與校驗；OCR只保留OCR與標注；其餘專頁不出現無關摘要入口 |
| 頁首「脫敏默認／證據追蹤／發布門禁」與重複路徑標題 | 移除 | 既非目前狀態，也非該頁可採取的動作；頁名、實際異常與下一步操作已足夠 |
| 頁腳固定職責邊界與技術層級說明 | 移除 | 權限由真正的功能與服務端控制；逐頁重複說教不協助排障 |
| OCR、向量、評測、成本、事件、版本等專業資料與原始診斷 | 保留於對應頁與詳情 | 是FDE實際診斷和治理所需資料，不能以精簡為由刪除 |
| 反饋歸因首屏8個全量品質指標 | 移至既有「品質指標」抽屜 | 使用者首先要篩選、分類與歸檔；全量品質分析為低頻工作，不應把待處理表格推下首屏 |
| 反饋頁的內部來源路徑、§17.3／F4／canUseForTraining文字 | 改任務用語 | 檔名、方案章節、程式欄位名稱不協助操作；保留真實樣本用途與規則發布限制 |
| 反饋／盲審清單的獨立ID欄及批次ID | 收進行內「關聯編號／任務與批次編號」 | 追蹤ID仍可取得，但首要資訊是項目節點、判定、意見、根因與動作 |
| 盲審頂欄橡皮圖章指數 | 保留於「盲審品質」抽屜 | 當前工作是依資料獨立判定；抽樣品質分析可另看，異常仍有提示 |
| 盲審「指數低即照抄AI」斷言 | 改為需進一步複核的品質提示 | 聚合指標不能單獨證明個人行為；不更改既有統計公式或閾值 |
| Triage 全局搜尋／任務中心原指向 admin | 修正為 fde | 此路由只屬FDE，入口應對應其角色範圍 |
| AI Run 頁兩組重複決策鏈、溯源、品質與修正區塊 | 保留完整一組 | 瀏覽器確認重複呈現同一資料；保留含診斷修正入口的完整區塊，審計證據與原文申請／重跑入口均保留 |

另確認反饋清單與品質指標原本採 Promise.all：可選品質統計失敗會阻止清單展示。現在分別處理成功與失敗，保留反饋操作，指標抽屜提示未取得；真實反饋載入錯誤仍顯示。沒有刪除API欄位、審計資料或變更業務權限。
