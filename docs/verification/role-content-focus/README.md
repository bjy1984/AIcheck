# 角色後台內容審計與精簡

本輪按角色完成工作的需要取捨資訊：主頁呈現當前任務、進度、結果與下一步；技術診斷只留在需要它的角色及對應專頁。

| 角色 | 保留的工作內容 | 移除或改為按需查看 |
| --- | --- | --- |
| 施工方 | 資料上傳、提交、補正意見、文件處理狀態 | 通用頁置信度/內部編碼/引用計數、文件OCR核驗分區、任務工程診斷 |
| 無損檢測 | 檢測資料、文件提交、退回補正、處理狀態 | 文件OCR核驗分區、任務工程診斷；處理狀態改為業務用語 |
| 建設方 | 項目與節點進度、異常、報告、歸檔、原文查看 | AI審查與工程側欄、OCR定位數、審查內部鏈路、多處只讀說明、通用頁核驗欄位 |
| 監檢 | 審查進度、資料證據、規範、字段/表格/印章核驗、人工意見 | 對話Token/供應商/工具次數、原始任務記錄、無操作價值的內部數字 |
| 系統管理員 | 項目/組織/使用者/權限、配置與發布、審計、知識處理 | 各頁重複全局統計與摘要；索引診斷、技術屬性按需展開 |
| FDE工程師 | 任務/模型/OCR/向量/成本/版本/事故排障 | 與當前專頁無關的全局摘要、重複標題/口號；低頻品質與編號按需展開 |
