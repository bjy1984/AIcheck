# 後台剩餘問題修復與逐頁確認

沿用上一輪的 [44頁／83張截圖](../uiux-optimization/index.html)，本輪先重現待確認問題，再依誤判風險與使用阻礙修復。保留原有產品設計、權限與既有功能。

**44/44個後台主路由、79張最終截圖全部目視確認，另保留10張修前對照，共89張。** [可搜尋圖集](index.html) · [逐頁覆蓋](coverage.md) · [逐張清單](manifest.json)。管理28張、知識16張、FDE21張、工作台14張；所有修後畫面均來自同一個 `dist-uiux-followup-final` 建置。中間QA圖片保留在分組資料夾作追溯，不計入本輪覆蓋。

## 已核對的資料／服務邊界

- 業務包名稱有manifest依據：compliance_audit_v1為長輸、device_inspection_v1為公用、engineering_inspection_v1為工業；domainType屬沿用識別碼，未為視覺一致性改寫配置。
- 舊EV-CA-001證據屬DV-CA-001-V1／節點1，而發現項位於節點3；節點證據API依授權範圍查詢，無法解析不是前端可安全猜測的對應。保留缺少精確證據提示，未放寬權限或把錯誤資料接到畫面。
- 項目原文NOT_FOUND、canonical未生成與外部OCR未配置仍是真實資料／服務狀態。修復提示與操作路徑不等於補齊實際文件或服務。
- 未使用正式資料庫、外部模型／OCR，未執行正式寫入、提交、合併或部署。

## 剩餘低優先呈現候選

審查點、知識來源／文件的多欄表仍可橫向捲動查看次要欄位；部分長項目名稱與規則差異仍使用省略提示。這些沒有阻擋本輪確認的關鍵狀態與操作，未宣稱所有長表都不需要捲動。
