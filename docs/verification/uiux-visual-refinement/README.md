# 狀態、圖標與圖表優化

本輪依已確認的介面問題落實狀態語義、邊框層級、導航與操作圖標，以及有實際比較價值的資料圖表。

## 修改範圍

- 全站共用明確狀態詞表：完成綠、執行中藍、待處理黃、失敗／阻斷紅、未知／停用灰；避免「待發布」「未通過」命中成功字串。狀態保留文字，搭配一致圖標。
- 修正未取得審計資料標紅，以及待人工確認跨頁紅黃不一致；導航與常用操作補上既有圖標。
- 導航、摘要與側欄減少漸層、重複框線與浮起效果；保留選中、焦點與問題區分。
- FDE 任務狀態使用後端分組件數，OCR 問題以單一統計口徑排序；移除任意評分、缺值補零與預設 80ms。
- 知識庫比較實際切片／向量件數；監檢呈現審計項狀態，並保留對應節點清單。

## 首輪逐頁驗證後補修

- 補齊已存在的專案／節點狀態與 AI 空格標籤，避免保守未知色遮掉已知執行中／補正狀態。
- 管理列表收合重複治理摘要；知識來源與專案文件把名稱／所屬資訊合併，確保 OCR、切片、向量狀態同屏可見；配置標題可換行。
- FDE 任務圖移到阻斷處理之後，新增 OCR 問題圖接入實際可開啟的品質統計對話框；目前頁面標記統一藍色。
- 後端聚合漏認「完成」導致圖表／列表不一致，已修正；缺失與未知狀態獨立計數，避免當成未開始。
- 施工方審核中改藍色時鐘，0 計數與未取得摘要改中性；通用工作台引用件數不再標紅，唯讀模式不當成成功狀態。

## 驗證

前端130個測試檔全數通過、TypeScript與production build通過；後端65項測試通過。**44 / 44 個後台主路由、55 張截圖已逐頁目視確認**；靜態操作性掃描637個檔案、0項問題。圖集僅納入同一個 `dist-uiux-visual-refinement` 建置的原始JPEG截圖，覆蓋44個後台主路由。

- 逐頁截圖：管理13頁、知識庫10頁、FDE16頁、工作台5頁；另含圖表互動、資料缺值與900px窄版導航。
- FDE實際點圖條跳任務清單，完成件數與列表一致；OCR品質標記／缺失字段口徑可切換。
- 監檢點選完成審計項，正確篩出含完成項的節點，未把部分完成說成整節點完成。
- 建設方實際切換有字段與無字段節點，均不會因OCR高信心或空陣列假報一致性通過。
- OCR正值圖與耗時缺值另以production元件實際computed option、ECharts SVG SSR測試驗證；瀏覽器樣本的OCR品質陣列為空，未冒充正值實測。

## 最後補充修正

- 窄版導航的圖標欄位由8px調整為16px並清除額外邊距，避免圖文重疊。
- 發現審查鏈路把空字段陣列、高信心OCR或字段已複核直接顯示「通過」；已改為「待核驗」，低信心／未知保留「需人工確認」，並補足實際computed回歸。

## 範圍與資料邊界

- 本輪以真實 API、隔離記憶體示例資料驗證；未對正式資料寫入，也未部署。
- 成功率／成本趨勢缺少時間分桶契約，不補造趨勢；低資料量頁保留簡單件數與表格。
- 原文缺失、canonical 未生成、外部 OCR 未配置等實際服務問題，保留真實提示。
