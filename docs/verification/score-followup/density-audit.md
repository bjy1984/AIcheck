# 知識總覽與無損檢測閱讀效率

## 已確認的問題與修正

- 知識總覽索引表只有兩列，舊版固定高度為 360px；1280×720 實測表格從 y=269.6 至 629.6，兩列內容約到 y=473，空白把知識源推到視窗底部。改為 `max-height="360"`，依資料內容收縮，保留載入、空態及長列表滾動上限。
- 無損檢測上下兩組大型摘要重複佔高。上層由工作台改為三項緊湊摘要；下層改為「已登記底片」「已導入記錄」「檢測報告」三項行內計數。已上傳文件與已登記資料保持各自口徑；移除把底片、記錄、報告相加的混合總量標記。
- 390px 舊版上傳表格固定操作欄佔去大部分可讀寬度，資料類型被截斷、業務規則需橫向尋找。窄版改為依資料類型分列，完整顯示名稱、上傳數與上傳入口；規則使用原生 `details` 按需展開。上傳入口沿用原有處理函式，不改文件歸類或提交行為。
- 已上傳文件的窄版展開清單保留在所屬類型下，桌面仍集中展示；狀態展開按鈕補充 `aria-expanded`。已上傳文件與監檢反饋表格改為最大高度，少量或空資料不再留下固定空白。
