# 反饋歸因可讀性修復

本輪依評分確認的問題調整 `FdeFeedbackTriage.vue` 及其顯示模型，未更動後端資料契約或審查判定。

- 舊表格8欄所需寬度超過約1300px；1280px桌面主內容區不足，固定歸檔欄擠壓根因與說明。現以緊湊工作列呈現：項目/節點及狀態在前，AI/人工結論與完整短說明靠左，歸因、用途及歸檔在同列右側。680px以下自然排成單欄，不依靠縮字或隱藏溢出。
- 超過140字的說明使用原生details，可用鍵盤展開全文；短說明直接完整呈現。原始回饋和分類仍留在按需展開的追溯資訊中。
- 已確認後端仍支援 `edited` 及歷史12類根因。顯示為「人工編輯」「提示詞問題（歷史分類）」等工作用語，選項、篩選及提交保留原始值，不把 `prompt_error` 自動合併為 `prompt`。
- 歷史分類只在目前資料實際存在時加入篩選與選項，避免展示無關舊分類。未知值仍可見原始代碼，不默認為「其它」或丟棄。
- 手機上的按鈕、選擇框與用途勾選行至少44px高；時間篩選與歸因選擇補上可存取名稱。
