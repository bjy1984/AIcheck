# 工作台評分後修復

## 已確認問題與修正

- 建設方在項目總覽仍顯示先前節點的麵包屑，容易誤認總覽只屬於該節點。麵包屑現在依目前區段顯示「項目總覽」或節點名稱；節點分類只在節點頁出現。
- 監檢待處理列表的長節點名稱被截斷。調整欄寬分配、允許節點名稱換行並維持可操作高度。
- 施工、建設、檢測在中等桌面寬度的頁首合併為單列；監檢仍保留較多控制項所需的兩列。900px 以下控制項正常換行，避免跑出視窗。
- 390px 施工頁實測固定雙欄令上傳區寬度為 0px。900px 以下改為單欄，保留上傳區與監檢意見的順序。手機摘要維持三項緊湊按鈕，空意見區減少裝飾高度。
- 無損檢測摘要合併為三項，避免與明細區重複佔高；已上傳與已登記數量不混算。
