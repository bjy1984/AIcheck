# 截圖驗證中追加的手機閱讀修復

這三項先由實際畫面與 DOM 尺寸確認，再做最小修改。

- **管理／FDE 共用工具列**：390px 視窗的工具區寬358px、內容寬477px；導航與任務按鈕被壓縮至44px卻同時顯示圖標及文字，帳號需要橫滑。改為自然換行，按鈕不壓縮，長帳號可換行，保留原有操作及可存取名稱。
- **項目快捷搜尋**：390px 手機使用桌面橫向表格，長節點結果只剩省略號，類型顯示 `node`。手機改為有完整標題、說明、命中內容及定位按鈕的清單，類型改為業務名稱。桌面仍保留表格，少量資料改用最大高度。定位沿用原有事件與處理函式。
- **檢測上傳抽屜**：長複選選項超出內層卡片邊界。實際元件為 `UploadSessionDrawer.vue`；調整網格及複選框最小寬度、標籤換行與首行對齊，未改動選取或上傳行為。
