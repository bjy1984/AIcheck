# 移除项目管理副标题设计

## 目标

从管理员后台“项目管理”页面移除“管理项目清单、项目详情和立项向导”副标题，同时保留页面标题、操作按钮和治理摘要卡。

## 设计

- 将项目管理页的副标题配置设为空字符串，其他管理页面副标题不变。
- 副标题为空时不渲染 `.page-subtitle` 元素，避免形成无内容的占位和上边距。
- 使用现有 Playwright 管理后台用例验证项目页不显示该文案，并验证页面标题仍可见。

## 验收标准

1. `/admin/overview` 和 `/admin/projects` 不显示“管理项目清单、项目详情和立项向导”。
2. 页面仍显示“项目管理”标题。
3. 其他管理页面的副标题逻辑不受影响。
