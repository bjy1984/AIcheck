# 复核工作台标题与条款弹窗位置调整设计

## 目标

- 将独立复核工作台页头标题从“AI 工程监检复核工作台”改为“压力管道监检工作台”。
- 将“标准条款定位”等共用证据定位弹窗的顶部位置固定为距浏览器可视区顶部 `32px`，使其明显高于 Element Plus 默认的 `15vh` 位置。

## 实现

- 在 `ConversationalReviewWorkbenchB.vue` 中只替换独立页面的品牌标题，不改变 AI 标识、项目切换器或嵌入式工作台。
- 在 `EvidenceLocatorDialog.vue` 的 `ElDialog` 上设置 `top="32px"`。该组件同时承载标准条款、OCR 字段和文件证据定位，三种定位弹窗保持一致位置。
- 不修改全局 `.el-dialog` 样式，避免影响项目内其他弹窗。

## 验证

- 增加静态回归测试，断言新标题存在且旧标题已删除。
- 增加静态回归测试，断言证据定位弹窗显式设置 `top="32px"`。
- 运行相关前端测试、类型检查和生产构建。
- 发布后检查服务器首页、API 就绪状态，并确认线上构建产物包含新标题与弹窗位置配置。
