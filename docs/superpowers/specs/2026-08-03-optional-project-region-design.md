# 项目区域改为选填

## 目标

修复项目立项向导在已经选择压力管道类别、已经自动生成项目类型后，仍提示“请填写项目类型和区域”的问题。区域字段继续显示，但改为选填。

## 字段规则

- `businessPackId`：必选，由用户选择压力管道类别。
- `type`：由所选业务类型自动生成，只读展示，不要求用户输入。
- `region`：选填；未填写时允许进入下一步并创建项目。
- `name`：必填。

## 前端行为

- 区域标签显示为“区域（选填）”，并提供示例占位提示。
- 第一步只校验压力管道类别、项目名称，以及系统是否成功生成项目类型。
- 不再因为区域为空阻止进入下一步。
- 自动生成项目类型异常时，提示“项目类型生成失败，请重新选择压力管道类别”，不再要求用户填写只读字段。

## 后端行为

- 创建项目接口不再把 `region` 列入必填字段。
- 未提供区域时保存为空字符串，保持现有字符串数据结构兼容。
- 业务类型仍以后端加载的业务包为准；请求携带的 `type` 与业务包不一致时继续拒绝。

## 测试

- 前端端到端用例覆盖区域为空时可进入“参建单位”步骤。
- 后端契约用例覆盖区域缺失时可以通过基础字段校验。
- 保留项目名称缺失、业务类型不一致、参建单位或初始成员无效的拒绝行为。

## 非目标

- 不引入行政区划字典或级联选择器。
- 不改变压力管道类别、节点模板和初始授权规则。
- 不修改既有项目的区域数据。
