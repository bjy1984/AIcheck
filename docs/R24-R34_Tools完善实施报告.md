# R24-R34 Tools 完善实施报告

日期：2026-07-17

## 1. 结论

改造前，现有 Tools **不能完整实现** R24-R34 的业务审核目标：R24 只覆盖少数焊工资格代号示例；R25-R34 多数专业 Tool 实际落入通用规则解释器，缺少专用事实装配和确定性规则参数，关键资料齐全时仍可能返回 `evidence_insufficient`，也存在把示例阈值误用为通用规则的风险。

本次已完成 R24-R34 专用审核链。系统现在能够从项目资料和 OCR 结果装配事实，调用固定专业 Tool，输出 `passed / failed / evidence_insufficient / not_applicable`，并在证据、条款 profile 或设计条件不足时 fail-closed。当前能力适合进入真实样本试点验收；它不替代监检人员的现场见证和正式签发。

## 2. 各节点实施结果

| 节点 | 已实现能力 | 仍需外部事实或人工见证 |
| --- | --- | --- |

| R26 | 核对 MTC 原件/受控复印件、牌号、规格、批号、实物追溯、库存期限/超期复验及化学/力学性能 | 必须提供对应焊材牌号的产品标准数值 profile；实物批号需现场见证 |
| R27 | 核对验收、库房温湿度、烘干、发放、使用和回收记录链，检查混用、过期及批号追溯 | 烘干、温湿度等限值来自设计/WPS/说明书的项目控制 profile |
| R28 | 按材料组别、厚度和接头数据检查错边、间隙、坡口及禁止强行组对 | 实物抽查/照片由现场提供；设计预拉伸须显式标注 |
| R29 | 以焊缝号关联焊工、WPS/PQR、实际电流/电压/焊速/层间温度和焊缝标识，并联动 R24/R25 | 施工记录真实性和钢印/标识现场一致性需见证 |

| R32 | 先按焊口材料/厚度/设计条件判 PWHT 适用性，再核对经批准工艺卡、评定报告、保温温度/时间和升降温速率 | 材料分类、最小抗拉强度或设计要求缺失时不猜测 |
| R33 | 与 R32 共享 PWHT 适用性；需要热处理时核对热电偶、温控仪和记录仪的校准证书、有效期及测温点布置图，全部焊口不要求热处理时返回不适用 | 仪表与实际热处理报告的设备编号关联、现场布点需见证 |
| R34 | 与 R32 共享 PWHT 适用性，检查曲线连续性、实际升温/保温/降温参数、炉内 10%/局部 100% 硬度抽检、焊缝/HAZ 测点和材料条件硬度上限 | 非 HBW 数据须提供可靠换算；设计条件或材料行不明时证据不足 |

## 3. 工程改造

- 专用规则：`backend/libs/review_tools/r24_r34_tools.py`。
- 焊工资格解析：`backend/libs/review_orchestrator/deterministic_tools.py`。
- R24-R34 事实装配：`backend/libs/review_orchestrator/r24_r34_facts.py`，并已接入执行器。
- OCR：新增管线汇总、焊材证明/管理、组对、外观、返修、热处理工艺/仪表/记录、硬度报告 profile 和深页扫描路由。
- 资料映射：R24-R34 已分别绑定适当资料类型；R31 返修后 NDT 为“发生返修时条件必传”。
- 标准包：新增 NB/T 47018-2017、GB/T 5117-2012、GB/T 8110-2020、GB 50236-2011，并补齐 R24-R34 的专业条款和 PDF 页级定位。
- 固定执行计划：194 条 atomicCheck 均有 requiredFacts、Tool 链和参数；R24-R34 标记为 `pilot_implemented`。

## 4. 验证结果

- Python 语法编译：通过。
- R24-R34 及执行器、业务包、标准条款、资料映射定向测试：136 passed。

- 全量回归（排除项目既有的 2 个 FDE 首页路由断言）：1056 passed、17 skipped、2 deselected。
- 项目既有非本次问题：部署报告仍要求 FDE 首页为 `/fde/projects`，实际角色配置为 `/fde/dashboard`，导致对应 2 个部署报告测试失败；与 R24-R34 审核链无关。

## 5. 上线建议

1. 用真实项目资料建立 R24-R34 每节点至少“合格、明确不合格、缺证、条件不适用”四类金样本。
2. 对 R24 现场身份、R26 实物批号、R28/R30 实物测量和 R33 测温点保留人工见证字段；未见证不得自动通过。
3. 按实际焊材牌号持续补充 GB/T 5117、GB/T 8110、NB/T 47018 的冻结产品标准 profile。
4. 在 2026-08-01 前完成 TSG Z6002-2026 全量代号表和证书过渡规则核验；完成前系统已设置为施行日后 fail-closed。
5. 试点金样本和现场验收通过后，再按节点将 `pilot_implemented` 提升为生产状态。
